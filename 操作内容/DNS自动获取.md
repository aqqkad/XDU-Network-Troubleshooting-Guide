# DNS 自动获取

## Win11

右键电脑右下角的网络状态图标，打开网络和Internet设置

![alt text](image-6.png)

![alt text](image-7.png)

选择你想要修改DNS的网络；无线请点击WLAN，有线请点击以太网。

![alt text](image-8.png)

### 以太网

点击DNS服务器分配的编辑按钮

![alt text](image-9.png)

在“编辑DNS设置" 页面切换手动为自动（DHCP)



![alt text](image-11.png)


![alt text](image-10.png)

切换完成后点击保存，返回上一个页面，可以看到分配变成了自动

![alt text](image-12.png)
